# Top Down Farmer Game (Unity / C#)

A small top-down farming prototype developed in **2 days** for a technical interview.  
Players can plant, harvest, eat, or sell fruits that grow over time, and use the profit to buy clothing, food, or new seeds.  
The game features a simple inventory system, shop interaction, and dialogue UI inspired by Undertale. 🌱🛍️👕

---

# Project Features

- 🕹️ **Controls** → WASD to move, Enter to interact with the shop when nearby  
- 🌾 **Farming System** → Fruits grow over time and can be harvested once ready  
- 🧺 **Inventory System** → Unified inventory used both by the player and the shop  
- 🛍️ **Shop System** → Buy and sell fruits, seeds, clothes, and consumables  
- 🧥 **Clothing System** → Equip and swap purchased outfits dynamically  
- 🧠 **Scriptable Objects** → Used to define shop items and their properties  
- 💬 **Dialogue System** → Undertale-style text boxes with subtitles for NPC/shop interactions  
- 💰 **Economy System** → Sell fruits for coins to expand farming options  
- 🎨 **Top Down Gameplay** → Simple and clear layout for quick interactions
